# NyanQuest BGM Generation Prompts

Gemini Music AI용 프롬프트 목록. 각 트랙 30초.
코드에서 크로스페이드 루프 처리 (끝 2초 페이드아웃 + 처음 2초 페이드인 겹침).
파일명 규칙: `{카테고리}_{번호}_{간략설명}.mp3`

## 2. 전투/긴장 (battle) - 10트랙

## 사용법

1. Gemini Music AI에서 위 프롬프트 복사 → 붙여넣기 → 생성
2. 30초 트랙 다운로드
3. 파일명 규칙대로 이름 변경: `{카테고리}_{번호}_{설명}.mp3`
4. `public/bgm/` 폴더에 저장
5. 코드에서 자동 매핑

### 파일 구조
```
public/bgm/
├── explore/
│   ├── explore_01_dungeon_crawl.mp3
│   ├── explore_02_forest_path.mp3
│   └── ...
├── battle/
├── puzzle/
├── calm/
├── comedy/
├── horror/
├── victory/
└── defeat/
```

**총 60트랙 × ~500KB = ~30MB** (Supabase Storage 또는 public/ 폴더)
